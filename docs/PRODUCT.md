# Продуктовая модель

BAR Replay Coach помогает новичку превратить просмотр собственного replay в одну понятную и проверяемую задачу для следующей тренировки.

## Проблема и гипотеза

После матча стандартные графики и длинный replay дают много фактов, но не всегда помогают выбрать, что именно тренировать дальше. Ключевая гипотеза:

> Краткий автоматический coaching report помогает новичку лучше понять следующую тренировочную задачу, чем самостоятельный просмотр общих графиков матча.

Пользовательская ценность этой гипотезы пока не доказана. Технически корректный report сам по себе не подтверждает, что он понятен новичку или улучшает следующую игру.

## Основной цикл

```text
пользователь открывает replay в BAR
→ явно выбирает один team
→ Replay Coach собирает подтверждённые наблюдения
→ соседние состояния объединяются в эпизоды
→ выбирается одна главная проблема
→ report назначает одну задачу на следующую тренировку
```

Во время replay панель показывает только статус анализа, выбранный team и число подтверждённых эпизодов. Она не подсказывает следующее игровое действие.

## Граница первого MVP

Поддерживается один exact context: `Ravaged Remake v1.2`, Cortex, Cortex Bot Lab и один выбранный team. Анализируются только:

1. продолжительный подтверждённый energy stall;
2. продолжительный простой первой завершённой Bot Lab;
3. первое расширение позднее provisional контрольного окна этого context.

Unknown API state не считается ошибкой игрока. Короткие колебания не становятся эпизодами. Уничтоженная фабрика не считается продолжающимся простоем. Team change и rewind полностью начинают analysis session заново.

Report содержит анализируемого игрока, карту и faction, одну главную проблему, не более трёх supporting episodes, осторожное объяснение, одну тренировочную задачу и ограничения анализа. Последовательность эпизодов может быть названа вероятным последствием, но не доказанной причиной поражения.

## Отличие от статистического виджета

Replay Coach не строит универсальный dashboard и не заменяет графики BAR. Графики показывают множество показателей; Coach отбирает только несколько заранее ограниченных наблюдений и сводит их к одному practice focus. Он не сравнивает игрока с топовыми участниками, не выставляет рейтинг и не использует генеративный AI.

## Opening practice

Существующий live opening coach сохранён как отдельный экспериментальный practice-режим. Он ведёт по одному Cortex/Bot Lab opening и не расширяется вместе с Replay Coach. Его [статическая шпаргалка](OPENING_GUIDE.md) остаётся comparator этого вторичного эксперимента.

## Критерий полезности

Будущая ручная проверка должна сравнить два сценария:

1. новичок самостоятельно смотрит replay со стандартной статистикой;
2. тот же тип пользователя получает Replay Coach report.

Сравнивается, понял ли пользователь главную проблему, смог ли назвать одну следующую задачу, повторил ли её в следующем матче и оказался ли report понятнее общих графиков. Этот продуктовый эксперимент не входит в технический MVP.
