# Energy-stall evidence

Область содержит technical evidence Phase 2–4 для наблюдения собственной экономики, lifecycle sampling и recovery flow.

Проверки подтвердили, что runtime может собрать необходимые собственные resource signals и провести recovery-card через наблюдаемый stall и восстановление. Это не доказывает, что карточка полезна новичкам или что такой диагноз объясняет все причины замедления строительства.

Raw telemetry и infolog остаются локальными. Текущий продуктовый смысл recovery принадлежит [`../../LEARNING_MODEL.md`](../../LEARNING_MODEL.md), а runtime-контракт — [`../../MVP.md`](../../MVP.md).
