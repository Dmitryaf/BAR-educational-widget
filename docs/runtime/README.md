# Runtime evidence

Здесь публикуются короткие, обезличенные отчёты о технических проверках. Это evidence конкретного запуска, а не текущая спецификация и не доказательство usefulness.

- [`energy-stall/`](energy-stall/) — наблюдение экономики, lifecycle и recovery flow;
- [`build-power/`](build-power/) — техническая build-power observability;
- [`opening/`](opening/) — context guards, replay research, expansion и completion memory.

Raw CSV и infolog остаются локальными рядом с отчётами и не публикуются. Перед использованием старого результата проверь exact context, version, длительность и совместимость schema. Неполный прогон или последняя незавершённая строка не считаются evidence.
